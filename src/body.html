Manual mode

Turn on automatic discovery

A browser can't open SMB connections, so finding machines on your network needs a small helper running on this PC. It runs in its own window, listens only on 127.0.0.1, and stops when you close it.

  1. Press Download helper and open arcos-share-agent.cmd from your downloads folder.
  2. Leave its window open. This panel turns into Connected on its own.

Using ArcOS from a device that can't run the helper? You can instead — it lands in U:/Home/Downloads, replacing any existing copy, and can be fetched later from the PC that will run it.

Helper address

Default is http://127.0.0.1:8790. Only change this if you run the helper on another port.
